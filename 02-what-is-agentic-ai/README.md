**What is Agentic AI?**
Agentic AI is a type of AI that can take the task or goal from user and then work towards completing on its own, with minimal human guidance.

Key Characteristic
- Autonomy
- Goal Oriented
- Planning
- Reasoning
- Adaptability
- Context Awareness
